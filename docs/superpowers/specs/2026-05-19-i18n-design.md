# Hexo CMS 国际化（i18n）设计文档

> **版本**: 1.0.0
> **日期**: 2026-05-19
> **状态**: 待实施

---

## 1. 概述

为 Hexo CMS 添加中英双语支持，设计可扩展的多语言架构，同时满足 Web 和 Desktop 端的复用与同步，以及插件贡献翻译文案的能力。

### 1.1 目标

| 目标 | 说明 |
|------|------|
| 中英双语 | 首期支持 zh/en，架构预留任意语言扩展 |
| Web/Desktop 复用 | 翻译基础设施 100% 共享，仅语言偏好检测方式不同 |
| 插件翻译贡献 | 插件通过 manifest 声明式贡献翻译，PluginHost 自动收集 |
| 渐进迁移 | 不破坏现有功能，逐模块替换硬编码中文 |

### 1.2 非目标

- 翻译编辑器 UI（后续可作为插件实现）
- 机器翻译/自动翻译
- RTL 语言支持（阿拉伯语等）
- 复数规则引擎（中英文无需，后续按需添加）

---

## 2. 架构决策

### 2.1 i18n 作为核心基础设施（非插件）

**决策**：i18n 由 `@hexo-cms/core` 和 `@hexo-cms/ui` 提供，不作为插件。

**理由**：

| 维度 | 核心基础设施 | 功能插件 |
|------|-------------|---------|
| 使用范围 | 每个 UI 组件都依赖 | 特定功能模块 |
| 可用性要求 | 必须 100% 可用，首屏渲染前就绪 | 可被禁用、可延迟加载 |
| 失败影响 | 应用不可用 | 单个功能缺失 |
| 类比 | DataProvider、React Context、路由 | SEO Inspector、Draft Coach |

若 i18n 作为插件：插件被禁用或加载失败 → 所有 UI 文案丢失 → 应用不可用。这违背插件设计原则「插件失败不影响核心功能」。

### 2.2 插件翻译通过 Manifest 内联声明

**决策**：翻译文案作为 manifest 的 `contributes.translations` 字段直接声明，不使用独立文件。

**理由**：
- 匹配现有模式：`settingsSchemas`、`dashboardWidgets` 等已在 manifest 中内联声明
- 插件文案量小：SEO Inspector、Draft Coach 等每个插件仅 5-20 条翻译
- 零额外基础设施：PluginHost 在 `discover()` 阶段即可静态扫描
- TypeScript 类型安全

## 4. 类型定义

### 4.1 位置：`packages/core/src/i18n/types.ts`

```ts
/** 语言标识 */
export type Locale = "zh" | "en" | (string & {});

/** 翻译资源：嵌套对象结构 */
export type TranslationResource = {
  [key: string]: string | TranslationResource;
};

/** 运行时使用的扁平化翻译映射 */
export type TranslationMap = Record<string, string>;

/** I18n 配置 */
export interface I18nConfig {
  /** 支持的语言列表 */
  locales: Locale[];
  /** 默认语言（回退语言） */
  defaultLocale: Locale;
  /** 各语言翻译资源 */
  resources: Record<Locale, TranslationResource>;
}

/** useI18n() 返回值 */
export interface I18nContextValue {
  /** 当前语言 */
  locale: Locale;
  /** 支持的语言列表 */
  locales: Locale[];
  /** 切换语言，会自动持久化 */
  setLocale: (locale: Locale) => void;
  /** 
   * 翻译函数
   * @param key 点号分隔的翻译键，如 "posts.page.title"
   * @param params 插值参数，替换模板中的 {{key}}
   */
  t: (key: string, params?: Record<string, string | number>) => string;
}
```

### 4.2 插件贡献类型扩展

位置：`packages/core/src/plugin/types.ts`，在 `PluginContributions` 中新增：

```ts
export interface PluginContributions {
  // ... 已有字段保持不变
  /**
   * 插件提供的翻译资源。
   * key 为 Locale（如 "zh", "en"），value 为扁平翻译映射。
   * 所有 key 应以插件 ID 前缀命名空间，如 "seo-post-checks.title"。
   */
  translations?: Partial<Record<Locale, Record<string, string>>>;
}
```

## 5. React 层实现

### 5.1 I18nProvider

位置：`packages/ui/src/i18n/I18nProvider.tsx`

```tsx
import { createContext, useContext, useState, useCallback, useMemo } from "react";
import type { I18nConfig, I18nContextValue, Locale, TranslationMap } from "@hexo-cms/core";

const I18nContext = createContext<I18nContextValue | null>(null);

function flattenResource(
  resource: Record<string, unknown>,
  prefix = "",
): TranslationMap {
  const result: TranslationMap = {};
  for (const [key, value] of Object.entries(resource)) {
    const fullKey = prefix ? `${prefix}.${key}` : key;
    if (typeof value === "string") {
      result[fullKey] = value;
    } else if (value && typeof value === "object") {
      Object.assign(result, flattenResource(value as Record<string, unknown>, fullKey));
    }
  }
  return result;
}

function interpolate(template: string, params?: Record<string, string | number>): string {
  if (!params) return template;
  return template.replace(/\{\{(\w+)\}\}/g, (_, key) => String(params[key] ?? `{{${key}}}`));
}

interface I18nProviderProps {
  config: I18nConfig;
  initialLocale?: Locale;
  onLocaleChange?: (locale: Locale) => void | Promise<void>;
  children: React.ReactNode;
}

export function I18nProvider({ config, initialLocale, onLocaleChange, children }: I18nProviderProps) {
  const [locale, setLocaleState] = useState<Locale>(
    initialLocale ?? config.defaultLocale,
  );

  // 扁平化所有翻译资源（只在 config 变化时重算）
  const maps = useMemo(() => {
    const result: Record<string, TranslationMap> = {};
    for (const loc of config.locales) {
      const resource = config.resources[loc];
      result[loc] = resource ? flattenResource(resource) : {};
    }
    return result;
  }, [config]);

  const t = useCallback(
    (key: string, params?: Record<string, string | number>): string => {
      // 1. 在当前语言中查找
      const currentMap = maps[locale];
      if (currentMap?.[key]) return interpolate(currentMap[key], params);

      // 2. 回退到默认语言
      const defaultMap = maps[config.defaultLocale];
      if (locale !== config.defaultLocale && defaultMap?.[key]) {
        return interpolate(defaultMap[key], params);
      }

      // 3. 找不到，返回 key 本身
      if (import.meta.env.DEV) {
        console.warn(`[i18n] Missing translation: "${key}" for locale "${locale}"`);
      }
      return key;
    },
    [locale, maps, config.defaultLocale],
  );

  const setLocale = useCallback(
    (newLocale: Locale) => {
      setLocaleState(newLocale);
      onLocaleChange?.(newLocale);
    },
    [onLocaleChange],
  );

  const value = useMemo<I18nContextValue>(
    () => ({ locale, locales: config.locales, setLocale, t }),
    [locale, config.locales, setLocale, t],
  );

  return <I18nContext.Provider value={value}>{children}</I18nContext.Provider>;
}

export function useI18n(): I18nContextValue {
  const ctx = useContext(I18nContext);
  if (!ctx) throw new Error("useI18n() must be used within <I18nProvider>");
  return ctx;
}
```

## 6. 语言检测与持久化

### 6.1 Web 端（`packages/web/src/routes/__root.tsx`）

```ts
function detectWebLocale(): Locale {
  // 1. localStorage 存储的偏好
  const stored = localStorage.getItem("hexo-cms-locale");
  if (stored === "zh" || stored === "en") return stored;

  // 2. 浏览器语言
  const browserLang = navigator.language.split("-")[0];
  if (browserLang === "zh" || browserLang === "en") return browserLang;

  // 3. 默认
  return "zh";
}

function persistWebLocale(locale: Locale) {
  localStorage.setItem("hexo-cms-locale", locale);
}
```

### 6.2 Desktop 端（`packages/desktop/src/renderer/src/routes/__root.tsx`）

```ts
async function detectDesktopLocale(): Promise<Locale> {
  // 1. IPC 读取持久化的偏好
  const stored = await window.electronAPI.invoke("get-locale");
  if (stored === "zh" || stored === "en") return stored;

  // 2. 系统语言（Electron app.getLocale()）
  //    在 preload 中暴露
  const systemLang = await window.electronAPI.invoke("get-system-locale");
  const lang = systemLang?.split("-")[0];
  if (lang === "zh" || lang === "en") return lang;

  // 3. 默认
  return "zh";
}
```

### 6.3 统一初始化模式

两端 `__root.tsx` 模式一致：

```tsx
function RootLayout() {

  useEffect(() => {
    detectLocale().then(setLocale);

  if (!locale) return null; // 或 loading skeleton

    locales: ["zh", "en"],
    defaultLocale: "zh",

      zh: { ...builtInZh, ...pluginZh },

  return (
    <I18nProvider
      config={i18nConfig}
      initialLocale={locale}
      onLocaleChange={persistLocale}
    >
      <DataProviderProvider ...>
        <PluginProvider ...>
          <CMSLayout>
            <Outlet />
          </CMSLayout>
        </PluginProvider>
      </DataProviderProvider>
    </I18nProvider>
  );
}
```

### 7.2 PluginHost 自动收集

在 `PluginHost.syncRuntimeContributions()` 中扩展，收集所有启用插件的 translations：

```ts
// packages/core/src/plugin/plugin-host.ts
private collectPluginTranslations(): Record<string, Record<string, string>> {
  const translations: Record<string, Record<string, string>> = {};
  for (const [pluginId, plugin] of this.manager.enabledPlugins()) {
    const pluginTranslations = plugin.manifest.contributes?.translations;
    if (!pluginTranslations) continue;
    for (const [locale, map] of Object.entries(pluginTranslations)) {
      translations[locale] = { ...translations[locale], ...map };
    }
  }
  return translations;
}
```


```
  common.save                          → "保存" / "Save"

```

## 10. 错误处理与回退策略

```
翻译查找优先级：
  1. 当前 locale 的翻译映射
  2. defaultLocale（zh）的翻译映射
  3. 返回 key 本身（开发环境 console.warn 警告）
```

| 场景 | 行为 |
|------|------|
| 翻译 key 不存在 | DEV: console.warn + 返回 key；PROD: 返回 key |
| locale 资源未定义 | 回退到 defaultLocale |
| 插值参数缺失 | 保留 `{{key}}` 原文 |
| 插件翻译冲突 | 后加载覆盖先加载（同 locale 同 key） |
| 语言切换 | 同步更新所有组件，无闪烁 |

## 13. 风险与边界

| 风险 | 缓解 |
|------|------|
| 翻译 key 命名冲突 | 核心 UI 和插件使用不同命名空间前缀 |
| 大量硬编码中文迁移工作 | 渐进式迁移，不影响现有功能 |
| SSR 语言检测闪烁 | html lang 属性在服务端设置，I18nProvider 用 initialLocale 避免闪烁 |
| Desktop IPC 新增通道 | 在 preload ALLOWED_CHANNELS 白名单中添加 |

### 明确不做

- 翻译编辑 UI（后续可选作为插件）
- 复数规则（中英文无此需求，有需求时扩展 t() 支持）
- 日期/货币格式化（用 Intl API，不走翻译系统）
- RTL 布局支持
